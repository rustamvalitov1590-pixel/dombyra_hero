# DombraHero — Интерактивный ИИ-тренажёр домбры

Интерактивная цифровая веб-платформа для обучения игре на казахском национальном инструменте — домбре, объединяющая пошаговый разбор кюев, точную настройку через микрофон, караоке-игру и персонального ИИ-наставника Нурали на базе Google Gemini.

## ✨ Основные возможности

1. **Интерактивный тренажёр кюев (`/learn`)**:
   - 20-ладовый синхронный гриф домбры с подсветкой открытых и зажатых струн.
   - Цифровая табулатура с тактами, направлениями ударов (қағыс: ↑/↓) и дугами легато.
   - Управление скоростью (0.4×, 0.6×, 0.8×, 1.0×), повтор фрагментов и управление пробелом.
   - Синтез натурального щипкового звука домбры на Web Audio API.

2. **Точный онлайн-тюнер домбры (`/tuner`)**:
   - Настройка инструмента через микрофон в реальном времени (автокорреляционный pitch detection).
   - Поддержка двух традиционных строев:
     - **Оң бұрау (Прямой)**: Нижняя G3 (196 Гц) / Верхняя D3 (146.8 Гц).
     - **Теріс бұрау (Обратный)**: Нижняя G3 (196 Гц) / Верхняя C3 (130.8 Гц).
   - Индикация отклонения в центах и динамические советы по натяжению колков.
   - Эталонный звук для настройки на слух.

3. **Караоке игра на домбре (`/karaoke`)**:
   - Микрофон слушает звук вашей физической домбры.
   - Оценка точности взятия каждой ноты (Perfect / Good / Miss).
   - Подсчет комбо, очков и итоговой точности исполнения.

4. **ИИ-наставник Нурали (Google Gemini 1.5 Flash)**:
   - Интерактивный сквозной маскот с анимацией взгляда (следит за курсором и пальцем).
   - Всплывающие подсказки с контекстными советами по игре и настройке.
   - Полноценный AI-чат для вопросов о кюях, Курмангазы, Дине Нурпеисовой и теории музыки.

5. **ИИ-распознавание аудио в табулатуру (`/record`, `/upload`)**:
   - Запись фрагмента через микрофон или загрузка аудиофайла (MP3/WAV) для транскрибации в табулатуру.

## 🚀 Запуск проекта локально

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 🛠 Стек технологий

- **Next.js 14 (App Router)** & React 18
- **TypeScript** & **Tailwind CSS**
- **Web Audio API** & **Tone.js**
- **Google Generative AI (Gemini 1.5 Flash)**
- **next-intl** (Казахский и русский языки)
